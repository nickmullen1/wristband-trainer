# Wristband Trainer

GW offense and defense number-call practice, with the existing embedded GW logo.

Team link: https://nickmullen1.github.io/wristband-trainer/

## Publish updates

Replace or edit `index.html` on the `main` branch and commit the change. GitHub Pages automatically publishes from `main` → `/ (root)`. The public URL stays the same. Allow the Pages deployment to finish before checking an update.

Keep the repository name `wristband-trainer` and account name `nickmullen1` unchanged to preserve the link. `.nojekyll` enables direct static hosting. No build tools or external logo files are required.

Highlighted team-sheet calls belong to WORD MODE and must not be added as answers for numbered practice questions.
